# Sharing with Agora

Notes and Agora exchange content through Android sharing. Notes shares notebook page images or
Markdown; Agora chooses the destination conversation. Agora can share selected response content
back into Notes, where the Markdown importer renders it using the ruled-writing editor.

**Format with AI** runs inside Notes with Notes-owned provider settings. It sends the page JPEG
and handwriting prompt, then lays out the returned Markdown locally. See [AI formatting](AI-FORMATTING.md).

The former dedicated Agora document/proposal protocol is retired in current Agora. Notes retains
its existing validated exchange receiver for compatibility with older clients. That receiver is
not the AI formatter and does not require Agora to be installed. Existing document validation,
URI grants and saved-notebook compatibility must remain intact.
