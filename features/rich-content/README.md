# Rich content

Reusable Android assets for sanitizing and rendering Markdown, static SVG, and Mermaid in Kalamos
WebView apps. It contains no app workflow or provider logic. Remote images, scripts, animation,
event attributes, foreign objects, and non-HTTPS links are rejected or removed.

Bundled third-party browser libraries and their licences live under
`android/src/main/assets/web/rich-content/vendor`.
