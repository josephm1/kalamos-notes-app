# Agent guide

Start with README.md, RULES.md and HANDOVER.md. Before touching ink, snapshots or refresh policy read docs/devices/bigme/INK-WRITING-GUIDE.md.

- Reusable neutral contracts/runtime: foundation.
- Ruled handwriting behavior: features/writing/workspace.
- Android writing assets: regenerate with npm run build:android; never hand-edit.
- Bigme daemon/e-ink behavior: devices/bigme.
- Notes routing, branding and integration: apps/notes.

This is the self-contained Notes export. Do not introduce sibling-repository dependencies, app-to-app dependencies, source-copy scripts, archived Planning or historical Write 2.0 implementations. The owner performs physical device testing. Agents may build, install when authorized and inspect logs; do not claim physical panel acceptance.
